# 555 Timer Projects

This folder contains Proteus simulations of the NE555 Timer configured in various modes.

## Projects

- 1 Hz Astable Multivibrator
- 10 Hz Astable Multivibrator
- 100 Hz Astable Multivibrator

Each project includes:

- Circuit schematic
- Design calculations
- Simulation screenshots
- Oscilloscope output
- Proteus project files
